# Dynamic Full-Stack Developer Portfolio

A full-stack MERN portfolio website designed to showcase professional information, technical skills, education, projects, and work experience through a dynamic and editable interface.

## Features

- Dynamic profile and introduction section
- Add and edit education, skills, projects, and experience
- Persistent data storage across page refreshes
- Project cards with GitHub and live demo links
- Contact section with professional links
- Responsive user interface

## Tech Stack

- **Frontend:** React.js, JavaScript (ES6+), CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install` in the frontend and backend directories.
3. Configure environment variables in the appropriate `.env` files.
4. Start the backend server.
5. Start the frontend development server using `npm run dev`.
